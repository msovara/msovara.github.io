# msovara.github.io

Personal site for [Mthetho Vuyo Sovara](https://msovara.github.io/). Static HTML for GitHub Pages.

## Local preview

Open `index.html` in a browser, or from this directory:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080.

## Publish

1. Push `main` to https://github.com/msovara/msovara.github.io
2. In the repository: **Settings → Pages → Deploy from a branch → `main` / root**
3. The site is served at https://msovara.github.io/

## Edit later

Copy lives in `index.html`. Styles are in `assets/css/styles.css`. The hero plate is `assets/img/current-and-cluster.png`.
